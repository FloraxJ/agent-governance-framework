# Автоматический роутинг моделей и бюджет рассуждений

Стратегия гибридного использования мультимодельного стека (Anthropic Claude, Google Gemini, OpenAI Codex/o-series) для максимизации качества и оптимизации стоимости.

---

## 1. Матрица разделения обязанностей
| Класс задачи | Рекомендуемая модель | Обоснование |
| :--- | :--- | :--- |
| **Сложная архитектура, ключевая бизнес-логика** | Claude (Sonnet / Opus) | Минимальный уровень галлюцинаций, строгое следование тонким правилам проекта. |
| **Исследование больших объёмов, логи, дампы** | Gemini (Pro / 1.5-2.0 / Flash) | Мега-окно контекста (1M+ токенов), высокая скорость обработки сырых данных. |
| **Кросс-модельное оппонирование (Adversarial Review)** | OpenAI (Codex / o-series / GPT-4o) | Исключение слепых зон разработчика за счёт взгляда модели из принципиально другого семейства. |
| **Фоновые рутинные чеки, поиск по файлам** | Быстрые/дешевые модели (Flash, Haiku) | Нулевая задержка, минимальный расход квоты. |

---

## 2. Потолок рассуждений (Reasoning Budget Ceiling)
- **Лимит по умолчанию:** В моделях с настраиваемым уровнем рассуждений (thinking tokens) уровень выставляется не выше **High** (`high`).
- **Запрет Extreme/XHigh:** Экстремальные профили рассуждений (`xhigh` / максимальный budget) запрещено включать автоматически — только по прямому запросу человека для критических математических или криптографических алгоритмов.

---

## 3. Защита от обрыва стрима на тяжелом контексте (>150k токенов)
- При разрастании контекста свыше 120–150k токенов модели с глубоким рассуждением склонны ловить сетевой таймаут шлюза API (`unexpected EOF`, `stream timeout`).
- **Предохранитель:**
  1. Не допускать попадания сырых логов и больших файлов в основной контекст (изолировать в субагентах);
  2. Если контекст приблизился к лимиту — выполнить сжатие/компактификацию истории (`/compact`) до запуска тяжелого этапа генерации;
  3. При необходимости переключиться на модель с меньшей латентностью ответа.

---

## 4. Разрешение сомнений
Если сложность задачи находится на стыке или выбор модели неочевиден — агент обязан явно запросить подтверждение у человека через диалоговый выбор вариантов, а не принимать решение молча.
