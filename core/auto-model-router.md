# Автоматический роутинг моделей и бюджет рассуждений

Стратегия гибридного использования мультимодельного стека (Google Gemini / Neon / Argon, Anthropic Claude, OpenAI Codex / o-series) для максимизации качества и оптимизации стоимости токенов.

---

## 1. Матрица разделения обязанностей
| Класс задачи | Рекомендуемая модель | Обоснование |
| :--- | :--- | :--- |
| **Архитектурное планирование и системный дизайн** | Связка: **Gemini (Neon / Pro)** + **OpenAI (Codex / o-series)** | Кросс-семейственное взаимное оппонирование (Adversarial Review). Gemini строит декомпозицию, Codex проверяет на слепые зоны. |
| **Сложный продакшен-код, тонкая логика, рефакторинг** | **Claude** (Sonnet / Opus) | Минимальный уровень галлюцинаций в строгих правилах проекта, чистое соблюдение контрактов и архитектурных инвариантов. |
| **Исследование больших кодовых баз, дамп логов, сетевой трейс** | **Gemini** (Neon / Pro / 1.5–2.0 / Flash) | Мега-окно контекста (1M–2M+ токенов), высокая скорость обработки сырых телеметрических данных. |
| **Кросс-модельное adversarial-ревью кода** | **OpenAI** (Codex CLI / o1 / o3 / GPT-4o) | Независимый взгляд внешней модели из другого семейства на алгоритмы, гонки и граничные случаи. |
| **Фоновые рутинные чеки, поиск по файлам** | Быстрые/дешевые модели (Gemini Flash, Claude Haiku) | Минимальная задержка и нулевой оверхед по квоте. |

---

## 2. Потолок рассуждений (Reasoning Budget Ceiling)
- **Лимит по умолчанию:** В моделях с глубоким рассуждением (thinking tokens / reasoning effort) рабочий профиль выставляется не выше **High** (`neon-high` / `argon-high` / `high`).
- **Запрет профилей XHigh / Extreme:** Профили максимального рассуждения (`xhigh`) запрещено включать автоматически — использовать **только с прямого подтверждения человека** для критических математических, сетевых или криптографических задач.

---

## 3. Защита от обрыва стрима на тяжелом контексте (>150k токенов)
- При разрастании контекста свыше 120–150k токенов модели с длинным рассуждением (например, `neon-high` / `argon-high`) склонны ловить сетевой таймаут шлюза API (`unexpected EOF`, `stream reading error`).
- **Предохранитель:**
  1. Не допускать попадания сырых логов и больших файлов в основной контекст (выносить ресерч в изолированные субагенты);
  2. Если контекст приблизился к лимиту — выполнить сжатие/компактификацию истории (`/compact`) до запуска тяжелого этапа генерации;
  3. При необходимости временно переключиться на модель с меньшей латентностью ответа (Flash / Sonnet).

---

## 4. Разрешение сомнений
Если сложность задачи находится на стыке или выбор между Gemini, Claude и Codex неочевиден — агент обязан явно запросить подтверждение у человека через интерактивный выбор вариантов, а не принимать решение молча.
